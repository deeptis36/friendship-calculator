# ❤️ Friendship Calculator

> Enter two names and discover your friendship score.

## ✨ What is Friendship Calculator?

**Friendship Calculator** is a fun, interactive browser experience that takes two names and generates a friendship percentage.

The goal is to make a simple calculation feel playful, visual, and surprising.

Enter:

```text
Your Name
     +
Friend's Name
     ↓
Friendship Calculation
     ↓
❤️ Friendship Score
```

## 🎯 How It Works

1. Enter your name.
2. Enter your friend's name.
3. Start the calculation.
4. Watch the friendship score animate from `0%`.
5. Discover your friendship level.

The same two names will produce the same result each time.

## 🎨 Experience

The interface is designed around a simple idea:

**Don't just show a percentage — make the user wait for it.**

The calculator uses:

* A dedicated calculation stage
* Animated percentage counting
* Animated friendship meter
* Friendship-level reveal
* Play-again interaction
* Responsive design
* A no-scroll layout

## ⚡ Privacy

No names are sent to a server.

The calculation happens entirely in the browser.
